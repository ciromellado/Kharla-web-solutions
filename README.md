# Kharla Web Solutions | Desarrollo Web, Landing Pages y PWAs

¡Bienvenido al repositorio oficial de **Kharla Web Solutions**! Este sitio web estático ha sido desarrollado bajo los más altos estándares de rendimiento, diseño responsivo y optimización moderna para la presentación de servicios digitales y aplicaciones web progresivas (PWAs).

## 🚀 Características del Proyecto

- **Estructura Modular:** Código HTML5 semántico limpio y separado de su diseño visual en CSS3.
- **Diseño Responsivo (Mobile-First):** Adaptado de manera fluida a dispositivos móviles, tabletas y computadoras de escritorio gracias al uso avanzado de CSS Grid y Flexbox.
- **Optimización de Recursos:** Imágenes en formato moderno `.webp` y control estricto de proporciones para evitar deformaciones visuales.
- **Formulario de Contacto Integrado:** Conexión directa y segura con el servicio de procesamiento de formularios (Formspree).
- **Enfoque SEO:** Metadatos optimizados para buscadores y motores de indexación.
